# WebCraft — лендинг для веб-студии

Учебный проект №1 для портфолио. Одностраничный сайт-визитка веб-студии: адаптивная вёрстка, мобильное меню, форма заявки.

## Что внутри

| Файл | Назначение |
|------|-----------|
| `index.html` | Разметка всех секций: шапка, герой, услуги, о нас, портфолио, форма, футер |
| `styles.css` | Стили: CSS-переменные, grid/flex-раскладки, адаптив от 768px |
| `script.js` | Мобильное меню, плавная прокрутка, тень шапки при скролле, обработка формы |
| `server.js` | Локальный сервер на стандартной библиотеке Node.js (без зависимостей) |

## Как запустить

```bash
node server.js
```

Откройте http://localhost:3000

Или просто откройте `index.html` двойным кликом — сайт работает без сервера.

## Чему учит проект

- **Семантическая разметка** — `header`, `section`, `footer`, `nav`, атрибуты `aria-label`
- **CSS-переменные** — цвета и отступы задаются в `:root`, меняются в одном месте
- **Grid и Flexbox** — `repeat(auto-fit, minmax(...))` для карточек, который сам подстраивается под ширину экрана
- **Адаптивность** — медиазапрос на 768px: меню превращается в бургер, сетки в одну колонку
- **Работа с DOM** — `querySelector`, `classList.toggle`, обработчик `submit` с `preventDefault`
- **Плавная прокрутка** — `scrollIntoView({ behavior: 'smooth' })` вместо `scroll-behavior` только в CSS
